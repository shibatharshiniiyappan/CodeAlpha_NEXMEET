# NEXMEET Demonstration Screenshots

This directory serves as the repository for application visual captures to accompany the CodeAlpha internship submission.

> **Note for Evaluators & Reviewers**:
> The image references below are formatted to display once screenshots are captured from a running instance and placed in this directory.

---

| File Name | View / Feature | Key Elements to Capture |

---

### How to Capture & Add Screenshots:
1. Run the application locally (`npm run dev`) or access the deployed Render URL.
2. Navigate to each view listed above and capture a high-resolution screenshot (1920x1080 recommended).
3. Save each image with the corresponding file name in this folder (`docs/screenshots/`).
4. Commit and push to GitHub:
   ```bash
   git add docs/screenshots/*.png
   git commit -m "docs: add application demonstration screenshots"
   git push origin main
   ```
